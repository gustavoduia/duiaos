# Como contribuir

Obrigado pelo interesse no DuiaOS!

Neste momento o projeto aceita **sugestões e relatos de problemas** pela aba
[Issues](https://github.com/gustavoduia/duiaos/issues).

**Contribuições de código (pull requests)** ainda não estão abertas. Quando
abrirem, cada contribuidor precisará assinar um Acordo de Licença do
Contribuidor (CLA), uma única vez, antes de o código ser aceito.

## Ao relatar um problema

Informe:

- a versão do DuiaOS (comando `cat /etc/os-release`);
- o computador e a arquitetura (x86_64 ou ARM64);
- o que você fez, o que esperava e o que aconteceu;
- se possível, a saída de `lspci -nn` para problemas de hardware.
