## O que muda
Depois da atualização DUIA-2026-0013, o computador podia terminar de ligar numa tela preta pedindo o
usuário em modo texto, sem a Tela de Entrada. Esta atualização corrige isso.

Se o seu computador está nessa tela, digite o seu usuário e a senha ali mesmo e rode:
`sudo apt update && sudo apt full-upgrade -y && sudo systemctl restart greetd`

## Detalhes
- Causa: para tirar o texto de terminal da tela, a 0013 passou a abrir a interface por meio de um programa de registro. Quando esse programa falha, a interface não abre.
- Agora a interface abre direto, e as mensagens dos programas vão para um arquivo temporário.
- Os testes do DuiaOS passam a conferir que a tela gráfica abre mesmo quando o registro não está disponível.
- O resto da 0013 continua valendo: ligar direto na logomarca, F12 para escolher o sistema e nenhum texto ao sair ou desligar.
