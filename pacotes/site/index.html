DuiaOS

Repositório de atualizações do DuiaOS. Um DuiaOS instalado já vem com ele configurado; para atualizar:

sudo apt update && sudo apt full-upgrade

Canais: estavel (versões lançadas) e teste (desenvolvimento). Chave pública: apt/duiaos.asc.

Os pacotes do DuiaOS são software proprietário, de uso regido pelo EULA.
