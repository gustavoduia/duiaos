---
title: Reiniciar no Windows
description: Vá para o Windows sem o pedido da chave do BitLocker.
---

1. Clique no símbolo do DuiaOS na Barra de Recursos (ou aperte <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Delete</kbd>).
2. Escolha **Reiniciar no Windows**.

O computador reinicia direto no Windows pelo próprio firmware, que é o jeito que o BitLocker espera. A opção
só aparece quando o Windows está instalado no mesmo computador. Na Tela de Entrada, ela fica no botão
**Energia**.

Veja também [O Windows pede a chave do BitLocker](/documentacao/problemas/bitlocker-pede-a-chave/).
