---
title: Atualizar o sistema
description: Mantenha o DuiaOS e os aplicativos em dia.
---

**Pelo Wise (mais fácil)**

1. Escreva para o Wise: "atualiza o sistema".
2. Ele mostra quantos pacotes vão mudar e o tamanho do download, e pergunta **Posso fazer isto?**
3. Clique em **Aprovar**. O andamento aparece no próprio cartão.

**Pelo terminal**

```
sudo apt update && sudo apt full-upgrade
```

As atualizações vêm do repositório oficial do DuiaOS, assinado digitalmente. Veja
[Como as atualizações funcionam](/documentacao/entenda/atualizacoes/).
