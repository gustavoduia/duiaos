---
title: Atalhos de teclado
description: Os atalhos do DuiaOS.
---

| Atalho | O que faz |
| --- | --- |
| <kbd>Super</kbd> + <kbd>Espaço</kbd> | Abre e fecha a Central de Aplicativos |
| <kbd>Super</kbd> + <kbd>W</kbd> | Abre e fecha o Wise |
| <kbd>Super</kbd> + <kbd>L</kbd> | Bloqueia a tela |
| <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Delete</kbd> | Menu de Energia |
| <kbd>Enter</kbd> (na Central) | Abre o primeiro resultado |
| <kbd>Esc</kbd> (na Central) | Fecha a Central |

A tecla <kbd>Super</kbd> é a do logotipo do Windows, na maioria dos teclados.
