---
title: Como as atualizações funcionam
description: De onde vêm as atualizações e por que são seguras.
---

O DuiaOS é baseado no **Debian 13**. As atualizações vêm de dois lugares:

- os repositórios do Debian, para a base do sistema e os aplicativos;
- o repositório do DuiaOS, para a interface, o Wise e a IA do sistema.

Os dois são **assinados digitalmente**: o computador só instala o que veio de quem diz ter vindo. O DuiaOS tem
dois canais: **estável**, para versões lançadas, e **teste**, para quem acompanha o desenvolvimento.

Antes de instalar, o sistema simula a atualização para mostrar exatamente o que muda, e nunca remove partes
essenciais.
