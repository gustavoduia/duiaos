# Modificações em software livre de terceiros

Toda alteração que o DuiaOS fizer em código de terceiros licenciado sob
GPL, LGPL ou outra licença que exija publicação (por exemplo, patches no
Calamares) fica aqui, uma pasta por componente, sob a licença do original:

```
modificacoes/
  NOME-DO-COMPONENTE/
    README.md        versão de origem, licença e o que foi alterado
    *.patch          as alterações
```

Até agora não há nenhuma modificação.
